# YouTick documentation

V1 is a controlled NEAR testnet wallet pilot, not a real-money launch. Test USDC / test NEAR have no real value. Social sign-in, card payments and bank payouts are future plans. See [V1 scope and open responsibilities](architecture/youtick-v1-product-scope.md).

The current product has one paid-video path: NEAR and USDC for job, payment and
access truth; Livepeer Studio for upload, processing and playback; and one
control-plane Worker.
